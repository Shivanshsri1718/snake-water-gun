# Snake Water Gun Game 🐍💧🔫

This is a simple Snake Water Gun game made using Python.

The game is based on the classic Rock Paper Scissors concept.

## Rules

- Snake drinks Water → Snake wins
- Water damages Gun → Water wins
- Gun kills Snake → Gun wins

## Features

- Random computer choice
- User input system
- Win/Lose/Draw result
- Simple Python logic

## Technologies Used

- Python
- Random Module

## How to Run

1. Install Python
2. Download the project
3. Open terminal in project folder
4. Run:

```bash
python main.py
